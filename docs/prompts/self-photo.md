# 朋友圈「同一个人」出图提示词（给 GPT / 即梦 / 可灵用）

她自己的形象固定成一个人：**长发（约到肩下到腰，深色）、不露正脸、生活照质感**。
出图时只替换「场景 + 动作 + 表情」，身份段一个字都别改。

## 一、身份段（每次都原样带上）

```
使用附图作为同一个人的身份参考。保持：深色长直发（肩下到腰）、身形偏瘦、
身高约 165、二十岁出头、常穿浅色上衣或宽松外套；不要改变脸型、发型长度、
发色、身形比例。她只出现一个人，不要生成第二个人。
人物不露正脸：背影、侧影、低头、手挡脸、镜头只拍到下半身或局部都可以。
画风：手机随手拍，自然光，轻微噪点，轻微手抖，不要影棚光、不要滤镜感、
不要商业广告感、不要二次元。
```

## 二、场景段（每次只换这一段）

按当天要做的事换一句，长度一句话就够：

- 吃饭：`场景：小饭馆靠窗的桌子，桌上一碗面和半碟小菜，傍晚的暖光。动作：低头挑面。镜头：侧后方半身。`
- 加班：`场景：晚上十一点的工位，屏幕还亮着，桌上有喝剩的咖啡。动作：单手托腮盯着屏幕。镜头：侧影，只拍到肩膀和手。`
- 发呆：`场景：阳台，晾着两件衣服，天有点阴。动作：抱着膝盖坐在地上发呆。镜头：背影，中景。`
- 地铁：`场景：早高峰地铁车厢，扶手和人群虚化。动作：抓着扶手站着，头微微低。镜头：侧后方，只到胸口。`
- 散步：`场景：小区楼下的路灯和树影，路面有点湿。动作：慢慢往前走。镜头：背影，脚和裙摆为主。`

## 三、负面词（追加在同一段末尾）

```
不要正脸特写、不要多人合影、不要网红妆、不要浓妆、不要logo和水印、
不要在画面里出现文字、不要过曝、不要 AI 感的平滑皮肤。
```

## 四、稳定的用法（对应网上通用做法）

1. 先出 1 张最满意的当「身份参考图」，之后每次上传它，而不是每次都重新描述长相。
2. 身份段固定、场景段只改一处；一次只改一个变量，出问题好定位。
3. 同一天最多出 2 张，选一张发；一周内重复用同一张也正常（真人也会）。
4. 想要「像随手拍」，就把构图写糙一点：半身、侧后、局部、背影，比正脸稳。

## 五、接进鲸鲸（现在已实现的规则）

- 配图优先选**没有清晰人脸**的照片（食物、街景、物件、猫、背影）。
- 必须出现人物时，只用 `data\moments\self\` 里的「她本人」图池（第一次用 Codex 写作时自动挑一张存进去），不再从微博抓陌生人。
- 文案允许重复日常小事（饿、困、不想上班），不为了不重复硬找事。
- 想让 Codex 每天画同一个人：把上面身份段 + 当天场景段丢给它出图，存进 `data\moments\self\`，
  文件名保持 `self-xx.jpg`，插件会把它当「她本人」优先使用。
