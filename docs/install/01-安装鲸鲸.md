# 安装 / 启动鲸鲸

## 方式 A：从源码跑（开发机）

```powershell
cd C:\dev\whale-girl
# 1) 起内核（监听 8787）
app\runtime\node.exe server.js

# 2) 起启动器（另开一个窗口）
app\WhaleLauncher.exe
```

启动器里点右上「启动」，等「内核 / 桥接 / 微信」三个绿点。

## 方式 B：用打包好的便携版

解压 `鲸鲸-portable-YYYYMMDD.zip` 后：

```
双击 启动.cmd   → 起内核
双击 WhaleLauncher.exe → 起界面
```

## 第一次要做的三件事

1. **扫码登录微信**（桥接页 → 登录）
2. **填 DeepSeek Key**：设置 → 模型 → API Key（也可用自定义接口）
3. **填主人 wxid**：设置 → 权限 → 主人（不填的话插件不会认你）

## 常见启动问题

| 现象 | 原因 | 处理 |
|---|---|---|
| 8787 占用 | 旧内核没关 | 任务管理器结束 node.exe |
| 桥接红 | 微信版本不匹配 | 看 `data\bridge.log` 的 `version` |
| 界面白屏 | 启动器与 app 目录版本不一致 | 用 `publish\` 里的 exe 覆盖 `app\` |
