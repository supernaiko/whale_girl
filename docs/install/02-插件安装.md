# 插件安装（含依赖与数据）

所有插件都是「一个目录 + 一步安装」，数据跟着插件走。

## 通用步骤

1. 把插件目录（如 `custom\plugins\whale-ops\`）里的 `plugin.json`、`plugin.js` 拷到：
   `app\data\plugins\`
2. 生成安装描述（`<id>.flow.json` + `<id>.flow-grant.json`）：
   ```powershell
   python scripts\install.py "C:\dev\whale-girl\app\data\plugins"
   ```
   或直接用 `dist\<id>-<ver>.zip` 在「插件市场 → 从本地安装」里装。
3. 打开 `插件市场 → 已安装`，确认开关是开的；需要时在「设置」里填参数。

## 本仓库的插件

| 插件 | 目录 | 依赖 | 数据位置 | 必需配置 |
|---|---|---|---|---|
| 电脑助手 whale-ops | `custom\plugins\whale-ops` | 无（用宿主 SDK） | `data\plugins\whale-ops.data` | `owners`（主人 wxid） |
| 记忆管家 whale-memo | `custom\plugins\whale-memo` | 无 | `data\plugins\whale-memo.data` | `owners` |
| 接话判定 yxn-gate | `custom\plugins\yxn-gate` | 无 | `data\plugins\yxn-gate.data` | 无 |
| 心情与好感 yxn-bond | `custom\plugins\yxn-bond` | 无 | `data\plugins\yxn-bond.data` | 无 |
| 说话方式 yxn-voice | `custom\plugins\yxn-voice` | 无 | `data\plugins\yxn-voice.data` | 无 |
| 本地回话 yxn-chat | `custom\plugins\yxn-chat` | 无 | `data\plugins\yxn-chat.data` | `mode`、`probability` |

> 插件「数据」就是它自己那个 `.data` 目录，备份时连目录一起拷即可。

## 外部工具（不进 git）

| 工具 | 被谁用 | 安装 |
|---|---|---|
| Codex CLI | whale-ops（`codex` 动作） | `npm i -g @openai/codex`，然后 `codex login` |
| DSH | 可选（`dsh` 动作） | 装 DeepSeek Harness 桌面版 |
| 微博 cookie | 朋友圈配图 | 浏览器登录微博后把 cookie 写进 `data\weibo.cookie` |

## 验证插件是否被加载

```powershell
curl.exe -s http://127.0.0.1:8787/api/plugins/status
```

返回里能看到插件 id 且 `enabled:true` 即正常。
