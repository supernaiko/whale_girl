# 备份、迁移与打包

## 三种包，别搞混

| 包 | 内容 | 用途 | 大小 |
|---|---|---|---|
| 数据包 | persona/config/memory/diary/stickers/`plugins\*.data` | 日常备份、只换电脑不换程序 | 几 MB |
| 全量包 | 数据包 + `app\` + `custom\plugins\` | 换机、给朋友 | 300–400MB |
| 源码包 | git 仓库（不含 app/publish/data） | 继续开发 | 几十 MB |

> 环境（Node/Python/.NET/Git）**不进 git、不进包**，新机器按 `00-环境准备.md` 装。

## 打全量包

```powershell
powershell -ExecutionPolicy Bypass -File tools\make-portable.ps1
```

产物：`dist\鲸鲸-portable-YYYYMMDD.zip`，结构：

```
鲸鲸-portable-YYYYMMDD\
  ├─ app\               程序本体（含 runtime）
  ├─ custom\plugins\    插件源码
  ├─ data\              运行数据（不含 accounts.json、settings.json、日志）
  ├─ docs\install\      这三份说明
  └─ 启动.cmd
```

**故意不打包**：`accounts.json`（微信登录态，换机必须重登）、`settings.json`（API Key）、日志文件。

## 新机器怎么恢复

1. 解压到任意目录（路径别含中文空格以外的问题不大）
2. 双击 `启动.cmd` 起内核
3. 双击 `WhaleLauncher.exe`，点「启动」
4. 扫码登录微信 → 填 Key → 填主人 wxid
5. 插件市场确认插件都在

## 只搬数据

界面：`备份与迁移 → 打包她现在的样子`，
命令行：拷 `app\data\` 下 persona.json / config.json / reminders.json / voice-*.json / memory / diary / personas / stickers / moments / plugins\*.data。
