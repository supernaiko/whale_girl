# 环境准备（换机 / 新机器）

鲸鲸本体是「自带运行时」的：`app\runtime\` 里有 Node 和 Python，理论上解压即用。
但**构建**和**部分插件**还需要下面这些。它们不放进 git，只在新机器上装一次。

## 必装（运行）

| 组件 | 版本 | 用途 | 装在哪 |
|---|---|---|---|
| Windows | 10/11 x64 | — | — |
| 微信 PC | 4.1.10.27 或 4.1.15+ | 桥接 | 官方安装包 |
| VB-CABLE | 最新 | 语音发送（可选） | 官方安装包 |

## 构建/开发才需要

| 组件 | 版本 | 用途 | 安装方式 |
|---|---|---|---|
| Node.js | 22/24 | 跑宿主 src、插件测试 | 官方 msi |
| Python | 3.12 | 桥接脚本 | python.org |
| .NET SDK | 10.x | 编译启动器 | dotnet-install.ps1 |
| Git | 2.x | 拉代码 | MinGit / 官方 |

> 建议统一装在 `C:\dev\tools\`（Node→`C:\dev\tools\node`、.NET→`C:\dev\tools\dotnet`、Git→`C:\dev\tools\git`），
> 这样脚本里的路径固定，换机不用改。

## 一键检查

```powershell
powershell -ExecutionPolicy Bypass -File tools\env-bootstrap.ps1
```

输出会告诉你缺什么、怎么装、装到哪个路径。
