# 本地回话（yxn-chat）交付报告

## 实现范围

- 在 `custom/plugins/yxn-chat/` 新增 API 4 插件、清单、README 和测试。默认模式为 `off`。概率模式按七类轻量话题尝试取句，兜底模式仅在生成上下文含失败信号时尝试取句。
- 活动池按权重、语气匹配度和最近使用时间做 softmax 抽样。返回本地正文前修饰短句，等待阅读与打字延迟。总延迟最多 45 秒，估算剩余预算不足时用剩余时间的 80%。
- 支持首次只读导入种子、每小时维护活动池、24 小时内素材去重，以及日志追加与活动池更新中断后的补写。配置、口吻权重、使用统计、素材和本地模型占位均可随插件数据目录迁移。计数和低内存告警写入该目录内的 `activity.log`。

## 已知限制

- 当前宿主在调用 DeepSeek 之前运行 `chat.generate`，该钩子输入不包含 `reason`、`error` 或 `finalText`。概率模式可直接使用，DeepSeek 失败兜底和学习只以模拟上下文验证。源码位置为 `src/pipeline/chat.js` 的 `decide()` 与 `pluginContext()`。
- 人名过滤依赖记忆元数据与 @ 标记，无法穷尽正文中未记载的人名。宿主把语音转写成普通文字且省略语音类型时，只有可识别的语音标记或语音请求能触发守卫。
- 宿主没有传入精确的执行截止时间，插件以消息时刻、当前时刻和清单中的 60 秒限额估算。小时维护在工作进程重启后重新计时。

## 本地模型接入位置

在 `plugin.js` 的 `generateLocalModelReply({ localModel, message, bucket, deadline })` 接入推理。调用点位于模式与守卫通过后、加权池采样前。函数目前返回空结果，调用方随后使用加权池并应用同一延迟。配置来自 `local-model.json`。
